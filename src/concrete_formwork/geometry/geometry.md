## Geometry

To manage the different shapes of the different components, it has been choosen to use a geometry library 
that allows the creation of different types of geometry, such as lines and surfaces. 
The library should also allow for the manipulation of these geometries, such as cutting and filling.

The choice is to use the `shapely` library, which is a popular library for geometric operations in Python. It provides a wide range of geometric operations, including union, intersection, difference, and buffering.
